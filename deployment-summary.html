🎯 Two Core Modes

1. Approach Mode

Students enter DSA problems and receive progressive hints without direct solutions:

  • Level 1: Conceptual clue pointing in the right direction
  • Level 2: Direction toward a strategy or idea
  • Level 3: Relevant data structure/algorithm suggestion
  • Level 4: Implementation guidance
  • Level 5: Pseudocode-level structure

2. Code Hint Mode

Students submit code and receive targeted feedback:

  • Analysis of current approach
  • Identification of inefficiencies or errors
  • Progressive hints without code rewriting
  • Preservation of student code ownership

⚡ Quick Deployment (5 minutes)

Prerequisites

  • GitHub account (create free at github.com)
  • MongoDB Atlas account (free tier at mongodb.com)
  • Google API key (from console.cloud.google.com)
  • Render account (free at render.com)

Steps

  1. Get MongoDB Connection String
    • Visit MongoDB Atlas
    • Create free cluster (M0)
    • Get connection string: mongodb+srv://user:pass@cluster.mongodb.net/stepwise-dsa
  2. Get Google API Key
    • Visit Google Cloud Console
    • Enable "Google Generative AI API"
    • Create API key
  3. Deploy to Render
    • Visit render.com
    • Connect your GitHub repository
    • Configure: Name, Environment (Node), Region, Branch (main)
  4. Add Environment Variables
    • MONGODB_URI: Your connection string
    • GOOGLE_API_KEY: Your API key
    • NODE_ENV: production
    • PORT: 5000
  5. Deploy!
    • Click "Create Web Service"
    • Wait for build (3-5 minutes)
    • Your app is live at https://stepwise-dsa.onrender.com

🎓 Learning Philosophy

StepWise DSA follows these principles:

  • ✅ Act as a mentor, not a code generator
  • ✅ Never give complete solutions immediately
  • ✅ Use progressive hints (5 levels)
  • ✅ Ask questions instead of giving answers
  • ✅ Encourage independent problem-solving
  • ✅ Adapt hints based on student response
  • ✅ Consider relevant edge cases
  • ✅ Point out issues without rewriting code
