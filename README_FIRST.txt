🎯 TWO CORE FEATURES READY TO USE

MODE 1: APPROACH MODE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Students enter DSA problems → receive progressive hints (5 levels)

Example:
  Input: "How do I solve Two Sum?"
  
  Level 1: "What happens if you check every pair?"
  Level 2: "What causes O(n²) complexity?"
  Level 3: "What data structure gives fast lookup?"
  Level 4: "How would you store that information?"
  Level 5: "Can you write pseudocode for this?"
  
  Result: Student discovers the solution independently!

MODE 2: CODE HINT MODE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Students submit code → receive targeted feedback

Example:
  Student's code: Nested loop O(n²) solution
  
  Level 1: "Your logic is correct. Look at complexity."
  Level 2: "Can you avoid searching the array repeatedly?"
  Level 3: "What data structure checks if a value appeared?"
  
  Result: Student improves their own code!

🎓 LEARNING PHILOSOPHY

The AI acts as a mentor, not a code generator:

✅ Never gives complete solutions immediately
✅ Uses progressive hints (5 levels)
✅ Asks questions instead of giving answers
✅ Encourages independent problem-solving
✅ Adapts hints based on student response
✅ Preserves student code ownership
✅ Points out issues without rewriting
✅ Considers relevant edge cases

Success metric: "Did the AI help students THINK?"
(not "Did it solve the problem?")
