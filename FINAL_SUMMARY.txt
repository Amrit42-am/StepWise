PROJECT OVERVIEW
================================================================================

StepWise DSA is a production-ready, AI-powered DSA learning assistant that helps
students learn Data Structures and Algorithms through guided hints instead of
direct solutions.

Tagline: "Learn the approach, not the answer."

Key Philosophy:
- Students receive progressive hints (5 levels) that guide thinking
- AI never gives complete solutions immediately
- Two core modes: Approach Mode and Code Hint Mode
- Supports independent problem-solving through mentoring

================================================================================
API ENDPOINTS (6 TOTAL)
================================================================================

POST /api/approach/analyze
  - Analyze DSA problem
  - Generate first hint
  - Create session
  - Returns: sessionId, hint, hintLevel, maxHints

POST /api/approach/next-hint
  - Get next progressive hint
  - Accepts student response
  - Returns: hint, hintLevel, maxHints, isMaxed

POST /api/code/review
  - Analyze submitted code
  - Generate first code hint
  - Create session
  - Returns: sessionId, hint, hintLevel, maxHints

POST /api/code/next-hint
  - Get next code hint
  - Accepts updated code or response
  - Returns: hint, hintLevel, maxHints, isMaxed

GET /api/session/:sessionId
  - Retrieve full session history
  - Returns: Complete session data with conversation

GET /api/health
  - Health check endpoint
  - Returns: Status and timestamp

DATA STORED IN MONGODB
================================================================================

Session Documents:
{
  userId: String,
  mode: 'approach' | 'code',
  problem: String,
  code?: String,
  language?: String,
  hintLevel: Number (0-5),
  hints: [String],
  conversation: [
    {
      role: 'user' | 'assistant',
      content: String,
      timestamp: Date
    }
  ],
  createdAt: Date,
  updatedAt: Date
}

Collections:
- sessions (stores all user sessions and conversations)

================================================================================
LEARNING PHILOSOPHY IMPLEMENTED
================================================================================

The AI mentor follows these principles:

1. ✅ Act as a mentor, not a code generator
   - System prompt emphasizes mentoring behavior
   - Progressive hints instead of solutions

2. ✅ Never give complete solutions immediately
   - Max 5 hint levels before stopping
   - Hints become stronger, not revealing

3. ✅ Use progressive hints
   - Level 1: Conceptual
   - Level 2: Direction
   - Level 3: Technique
   - Level 4: Implementation
   - Level 5: Pseudocode

4. ✅ Ask questions instead of giving answers
   - System prompt trained to ask
   - Socratic method implemented

5. ✅ Encourage independent problem-solving
   - Hints guide, don't solve
   - Student discovery emphasized

6. ✅ Adapt hints based on response
   - Conversation history tracked
   - Next hints based on previous interaction

7. ✅ Consider edge cases
   - System prompt mentions edge cases
   - Encourages boundary thinking

8. ✅ Point out issues without rewriting
   - Code Hint Mode preserves student code
   - Only hints about improvements
