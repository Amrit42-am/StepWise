# Contributing to StepWise DSA

Thank you for your interest in contributing to StepWise DSA! We welcome contributions from everyone.

## How to Contribute

### Reporting Issues
- Check if the issue already exists
- Describe what happened and what you expected
- Include steps to reproduce
- Mention your environment (OS, Node version, browser)

### Suggesting Enhancements
- Describe the enhancement clearly
- Explain why it would be useful
- Provide examples if possible

### Submitting Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test locally
5. Commit with clear messages
6. Push to your fork
7. Open a Pull Request

### Development Setup

```bash
# Clone your fork
git clone https://github.com/your-username/StepWise.git
cd StepWise

# Install dependencies
npm install

# Create environment file
cp .env.example .env
# Edit .env with your credentials

# Start development server
npm run dev
```

### Code Style

- Use clear, descriptive variable names
- Add comments for complex logic
- Follow existing code patterns
- Keep functions small and focused

### Commit Messages

Use clear, descriptive commit messages:
- ✅ `Fix: Correct hint generation logic`
- ✅ `Feature: Add support for multiple languages`
- ✅ `Docs: Update deployment instructions`
- ❌ `fixed stuff`
- ❌ `updates`

## Areas for Contribution

- **Backend**: API improvements, AI prompt optimization, performance
- **Frontend**: UI/UX improvements, accessibility, responsiveness
- **Documentation**: Guides, tutorials, API documentation
- **Testing**: Test coverage, bug reports
- **DevOps**: Deployment improvements, CI/CD

## Questions?

Open a GitHub Discussion or Issue. We're here to help!

Thank you for contributing to making DSA learning better! 🎉
