🚀 StepWise DSA - Render Deployment Guide

Important: Before deploying, ensure you have:

  • GitHub account with the repository pushed
  • MongoDB Atlas account (free tier works)
  • Google API key for Generative AI (Gemini)
  • Render account

Step-by-Step Deployment

1️⃣ Prepare Your Repository

Make sure all files are committed and pushed to GitHub:

git add . git commit -m "Initial StepWise DSA commit" git push origin main

Your repository should contain:

  • package.json - Node dependencies
  • server.js - Express backend
  • client/public/index.html - Frontend
  • .env.example - Environment template
  • render.yaml - Render configuration
  • README.md - Documentation

2️⃣ Set Up MongoDB Atlas

  1. Go to MongoDB Atlas
  2. Create a free account or sign in
  3. Create a new cluster (free tier M0)
  4. Create a database user with strong password
  5. Get connection string:
    mongodb+srv://username:password@cluster.mongodb.net/stepwise-dsa?retryWrites=true&w=majority
  6. Save this connection string - you'll need it for Render

3️⃣ Get Google API Key

  1. Go to Google Cloud Console
  2. Create a new project (or select existing)
  3. Enable "Google Generative AI API"
  4. Create an API key (Credentials → Create Credentials → API Key)
  5. Copy your API key - keep it secure

4️⃣ Deploy to Render

  1. Go to Render.com
  2. Sign up with GitHub (recommended)
  3. Click "New +" → "Web Service"
  4. Connect your GitHub repository
  5. Configure the service:
    Setting Value
    Name stepwise-dsa
    Environment Node
    Region Closest to you
    Branch main
    Build Command npm install
    Start Command npm start
    Instance Type Free (or Paid)

5️⃣ Set Environment Variables

In Render dashboard, go to Environment and add these variables:

Key Value Notes
MONGODB_URI Your MongoDB connection string From MongoDB Atlas
GOOGLE_API_KEY Your Google API key From Google Cloud Console
FRONTEND_URL Your Render URL Will be: https://stepwise-dsa.onrender.com
NODE_ENV production Sets production mode
PORT 5000 Backend port

6️⃣ Deploy

  1. Click "Create Web Service"
  2. Render will build and deploy your app
  3. Wait for the build to complete (3-5 minutes)
  4. Once live, you'll see Your service is live
  5. Your app is now at: https://stepwise-dsa.onrender.com

7️⃣ Verify Deployment

Test these URLs to verify everything works:

  • https://stepwise-dsa.onrender.com - Frontend
  • https://stepwise-dsa.onrender.com/api/health - Health check

Troubleshooting

❌ Build Fails

  • Check the build logs in Render dashboard
  • Ensure package.json is in root directory
  • Make sure all dependencies are listed
  • Try pushing a new commit to trigger rebuild

❌ App Crashes After Deploy

  • Check service logs in Render dashboard
  • Verify all environment variables are set correctly
  • Check MongoDB connection string (whitelist IP in Atlas)
  • Ensure Google API key is valid

❌ API Returns 500 Errors

  • Check service logs for detailed error
  • Verify MongoDB connection: MONGODB_URI format
  • Test with a simpler request first
  • Make sure API key has correct permissions

❌ Frontend Not Loading

  • Make sure FRONTEND_URL matches your Render URL
  • Check browser console for CORS errors
  • Verify the HTML file is in client/public/index.html
  • Clear browser cache

💡 Tips

  • Auto-Deploy: Render auto-deploys when you push to main
  • Free Tier: Free tier sleeps after 15 min of inactivity, takes 30s to wake
  • Logs: Always check Render dashboard logs when debugging
  • MongoDB IP: Add Render IP to MongoDB Atlas whitelist if needed
  • Secrets: Never commit .env - use Render's environment variables
